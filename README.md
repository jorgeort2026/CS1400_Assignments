Multi-Vehicle Driving Cost Calculator
A command-line Python program that calculates and compares the cost of a trip across three vehicle types — a gas car, a truck, and an electric car. The user enters current gas and electricity prices, and the program computes per-trip cost for each vehicle type across a range of trip distances (50–500 miles), using separate cost models for combustion vehicles (miles-per-gallon × fuel price) and electric vehicles (watt-hours per mile × electricity price). Built to make real-world cost tradeoffs between vehicle types easy to visualize.
